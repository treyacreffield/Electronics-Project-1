# Electronics-Project-1
Memory and Math Game Program
Sequential game flow:
1. Simple start up screen 'Memory Game'
2. User presses any button to start
3. LEDs flash in random sequence, user is promted to watch
4. User then inputs memorised sequence, corresponding LEDs light up as user does this
5. If user gets sequence correct then next round becomes harder (longer sequence), and user scores a point /
If user gets sequence incorrect they lose a 'life' and next round remains at the same difficulty level
6. When user loses all lives or completes all rounds, game ends and a simple End Screen is displayed with overall score
